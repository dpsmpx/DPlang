# Планы разработки языка

Как читать:

- `[+]` — сделано, `[ ]` — открыто.
- Этапы идут по порядку; текущий — первый открытый. Этап 2 идёт
  следующим по решению автора (Р24); порядок этапов 3–6 — план,
  меняется правкой здесь.
- У этапа — **ворота**: условие, без которого следующий не начинается.
  Сравнения в воротах — по порядку целей Р6: сначала корректность, потом
  скорость разработки и токены.
- **Срок.** Язык получает ориентировочно 1/6 рабочего ресурса автора и
  развивается параллельно VoxelRPG; календарных сроков нет, VoxelRPG
  язык не ждёт (Р21).
- **VoxelRPG.** До v1.0 основная кодовая база VoxelRPG на язык не
  переносится; можно — тесты компилятора, замеры, синтетические
  проекты, proof-of-concept и тестовые приложения (Р22). После v1.0
  перенос решается только в `DECISIONS.md` VoxelRPG — вне этого плана.
- Решения — [`docs/direction/DECISIONS.md`](../docs/direction/DECISIONS.md);
  хвосты и подтверждённый долг — [`TODO.md`](../TODO.md).

## <a id="by-size"></a>Сложность

Метка у задач и в `TODO.md`: `М` — мелкая, быстрая, безопасная; `С` —
средняя; `Т` — тяжёлая; `К` — капитальная. Это цена и риск, а не
очередь.

## <a id="stages"></a>Этапы

### [+] Этап 0. Постановка и исследование

Главная задача и требования (Р1–Р2), исследование
(`docs/research/`), инженерная культура VoxelRPG (Р3).

### [+] Этап 1. Решения автора

Р4–Р24, 3 октября 2026: проприетарная лицензия (временная редакция в
`LICENSE`), закрытый проект, порядок целей, решения по П1–П14, срок
относительно VoxelRPG, использование в VoxelRPG только после v1.0,
смысл v1.0, решения по замеру. Отложено — `DECISIONS.md`, раздел 5.

### [ ] Этап 2. Замер до компилятора (Р24)

- `С` **Эталонный набор**: 10–20 типичных задач системного и игрового
  кода — описанием задачи, без кода VoxelRPG; решения на C++ и тесты к
  ним — база сравнения. Набор — внутренний материал (Р5).
- `С` **Опыт с синтаксисом**: одна программа в 2–3 вариантах синтаксиса;
  токены на токенизаторе; модель с короткой спецификацией каждого
  варианта решает задачи набора — правильность (тесты), число циклов
  «ошибка — правка» и токены на принятое решение.

Кода компилятора на этапе нет; прототипы для замера — не компилятор.

**Ворота:** вариант синтаксиса выбран по мерам `GOAL.md` (раздел 2) в
порядке Р6 и записан решением.

### [ ] Этап 3. Спецификация ядра

- `Т` Спецификация в ориентире ~20 тыс. токенов (Р20), пример на каждый
  раздел, однозначная грамматика (Р7).
- `С` Закрыть отложенное: дополнительные статические гарантии памяти
  (Р9), механизм обнаруженного нарушения (Р11), точная формулировка
  гарантии детерминизма (Р12), представление строк и числовые
  преобразования (Р8).

**Ворота:** спецификация проходит опыт этапа 2 не хуже выбранного
варианта.

### [ ] Этап 4. Компилятор-срез

**Вход:** окончательный текст лицензии или решение автора оставить
временную редакцию до первого production-кода (Р4).

- `К` Фронтенд → IR → интерфейс бэкенда → C-бэкенд (Р16); команды
  `check`, `build`, `test`, `fmt` (Р15); машиночитаемая диагностика;
  блоки тестов (Р13).
- `С` UI-тесты компилятора (исходник + ожидаемый вывод) и замер
  скорости `check`; целевые показатели — по итогам замера (Р15).

**Ворота:** на эталонном наборе модель пишет на языке не менее
корректно, чем на C++, и тратит меньше токенов.

### [ ] Этап 5. Срез на устройствах

- `Т` Тестовое приложение: окно, треугольник Vulkan и звук SDL3 на
  Linux, Windows (clang + MinGW-w64) и Android (NDK); привязки Vulkan из
  `vk.xml` и SDL3 (Р17).
- `С` Повтор детерминированной симуляции на arm64 и x86-64 (Р12).

**Ворота:** запуск на трёх целях; повтор совпадает побитово.

### [ ] Этап 6. Путь к v1.0 (Р23)

- `К` Стабильная базовая спецификация; компилятор production-качества;
  C ABI; гарантии детерминизма; фаззинг и регрессионный набор;
  диагностика, форматировщик, инструменты сборки и тестов;
  документированные runtime и ABI; воспроизводимые сборки; политика
  совместимости и редакции с миграцией (Р0, Р18).
- `К` Проверка на крупном production-style проекте (не обязательно
  VoxelRPG).

**Ворота:** все пункты Р23 выполнены.
