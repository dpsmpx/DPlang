# Планы разработки языка

Как читать:

- `[+]` — сделано, `[ ]` — открыто.
- Этапы идут по порядку; текущий — первый открытый. Порядок этапов —
  **предложение** исследования (`docs/research/LANGUAGE_RESEARCH.md`,
  разделы 5 и 9); решением станет записью в
  [`docs/direction/DECISIONS.md`](../docs/direction/DECISIONS.md).
- У этапа — **ворота**: условие, без которого следующий не начинается.
- Хвосты и подтверждённый долг — [`TODO.md`](../TODO.md).

## <a id="by-size"></a>Сложность

Метка у задач и в `TODO.md`: `М` — мелкая, быстрая, безопасная; `С` —
средняя; `Т` — тяжёлая; `К` — капитальная. Это цена и риск, а не
очередь.

## <a id="stages"></a>Этапы

### [+] Этап 0. Постановка и исследование

Главная задача и требования (`GOAL.md`, Р1–Р2), исследование
(`docs/research/`), перенос инженерной культуры VoxelRPG (Р3).

### [ ] Этап 1. Решения автора по предложениям

`С` Решить П1–П15 исследования и отложенные решения `DECISIONS.md`
(раздел 5): лицензия, открытость, порядок целей, срок относительно
VoxelRPG, имя.

**Ворота:** записаны решения по лицензии, открытости и П1–П10.

### [ ] Этап 2. Замер до компилятора

- `С` Эталонный набор: 10–20 типичных задач VoxelRPG — описанием задачи,
  без выноса кода; решения на C++ — база сравнения.
- `С` 2–3 варианта синтаксиса на одной программе; токены на токенизаторе;
  модель с короткой спецификацией решает задачи набора — ошибки и токены
  на правильный результат.

**Ворота:** выбран вариант синтаксиса по мере `GOAL.md`, раздел 2.

### [ ] Этап 3. Спецификация ядра

`Т` Спецификация в бюджете токенов (до 20 тыс.), пример на каждый
раздел; грамматика однозначная.

**Ворота:** спецификация проходит опыт этапа 2 не хуже выбранного
варианта.

### [ ] Этап 4. Компилятор-срез

`К` Разбор, проверка типов, сообщения об ошибках, генерация C с `#line`,
блоки `test`, команды `check`/`build`/`test`/`fmt`; UI-тесты
компилятора (исходник + ожидаемый вывод); замер скорости `check`.

**Ворота:** эталонный набор решается моделью на языке не хуже, чем на
C++, и дешевле по токенам.

### [ ] Этап 5. Срез на устройствах

`Т` Окно, треугольник Vulkan и звук SDL3 на Linux, Windows (MinGW) и
Android (NDK); привязки Vulkan из `vk.xml`.

**Ворота:** запуск на трёх целях.

### [ ] Этап 6. Первая подсистема VoxelRPG

`К` Только после решения в `DECISIONS.md` VoxelRPG. Лист без рендера
(предметы, ремесло, прогрессия) — на языке через C ABI; приёмка —
проверки подсистемы и повтор симуляции: хэш состояния совпадает с C++.

**Ворота:** эквивалентность и замер против C++.

### [ ] Этап 7. Новое в VoxelRPG — на языке; перенос по подсистемам

`К` По тем же воротам; glm → встроенная математика, toml++ → разбор на
языке, EnTT → ECS на языке; платформа и рендер — последними и только по
замеру.
