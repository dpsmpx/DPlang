# tomlcheck — первая программа на dpl

Проверка файлов подмножества TOML (`ROADMAP/IMPLEMENTATION.md`, v0.1,
шаг 12). Программа целиком на dpl. Она проверяет язык на настоящей
задаче: модули, перечисления с данными, `match`, ошибки и `try`, строки,
`List`, стандартная библиотека (`os`, Р51) и тесты `@test` (Р50).

| файл | что |
|---|---|
| `toml.dpm` | разбор одной строки: `toml.parse_line(line) LineError!Line`; тесты разбора |
| `main.dpm` | программа: файлы из аргументов, повторы ключей и таблиц, отчёт; тесты отчёта |
| `samples/` | файлы для запуска: верный, с ошибками, CRLF, не UTF-8 |
| `expected/` | ожидаемое: отчёт тестов, вывод запуска и его аргументы |

## Подмножество

Файл — текст UTF-8, строки разделены LF или CRLF. Строка бывает:
- **пустой** — только пробелы и табуляции — или **комментарием** от `#`
  до конца строки;
- **заголовком таблицы** — `[имя]`. Пробелы внутри скобок допустимы, после
  заголовка — только комментарий. Пары после заголовка относятся к этой
  таблице;
- **парой** — `ключ = значение`, после значения — только комментарий.

Ключ и имя таблицы начинаются с `a`–`z` или `_`; дальше — `a`–`z`,
`0`–`9`, `_`. Значение — одно из трёх:
- целое `i64` в десятичной записи со знаком `+` или `-` или без него;
- `true` или `false`;
- строка в кавычках `"…"` без экранирования и без `"` внутри.

Ошибки:
- строка не по этим правилам;
- ключ повторён в своей таблице (или до первой таблицы);
- таблица повторена.

Остальное из TOML — точки в ключах, массивы, вложенные таблицы,
экранирование, числа с плавающей точкой, даты — подмножество не берёт.

## Запуск

```sh
dpl build -o tomlcheck examples/tomlcheck/main.dpm
./tomlcheck config.toml other.toml
```

- **Верный файл** — строка в stdout: `файл: ok, N keys in M tables`.
- **Ошибка** — строка в stderr: `файл:строка: error: сообщение`. Файл
  нельзя прочитать — `файл: error: …`.
- **Код выхода** — 0, если все файлы верны. Если есть ошибки или не дано
  ни одного файла, `main` возвращает `Failure`: код 1 и строка
  `error: main failed with Failure.Invalid` (или `Failure.Usage`) —
  `docs/spec/core.md`, trap.exit.

Пример вывода — `expected/run.out`; аргументы этого запуска —
`expected/run.args`.

## Проверки

Проход `example` в `tests/run.py` (`docs/compiler/cli.md`, раздел 7):
- `example/tomlcheck/test` — `dpl test main.dpm`: семь тестов разбора и
  отчёта под ASan и UBSan, ожидаемое — `expected/test.out`;
- `example/tomlcheck/run` — запуск эталонным интерпретатором на
  `samples/`, ожидаемое — `expected/run.out`;
- `example/tomlcheck/build` — `dpl build --release` и тот же запуск:
  вывод нативной программы совпадает с интерпретатором;
- `example/tomlcheck/fmt` — исходники в каноническом виде
  (`dpl fmt --check`).
