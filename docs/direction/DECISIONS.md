## 1. Модель проекта

```
Репозиторий C-
│
├── Язык: спецификация (в бюджете токенов) и редакции
├── Компилятор: разбор, проверка типов, бэкенд(ы), диагностика,
│   команды check / build / test / fmt / fix / query
├── Стандартная библиотека: коллекции, строки, математика, хэндлы,
│   арены, ECS-хранилище, TOML, задачи, журнал, тесты
├── Привязки: C ABI, Vulkan из vk.xml, SDL3, JNI
├── Проверки: тесты компилятора, фаззинг, замеры скорости и токенов
└── Эталонный набор задач — мера целей (GOAL.md, раздел 2)

Первый потребитель — VoxelRPG (отдельный закрытый репозиторий
dpsmpx/3D_Voxel_OpenWorld_RPG).
```

## 2. Решения

### Р0. Совместимость — по мере появления потребителя
- **Решение.** Пока на языке нет кода VoxelRPG, совместимость не
  поддерживается: синтаксис, семантику, форматы компилятора можно менять
  свободно. С первого модуля VoxelRPG на языке изменения языка идут
  только так, чтобы игру не переписывать (Р2).
- **Почему.** До потребителя совместимость — только тормоз; после —
  требование автора. Основание — правило VoxelRPG «совместимость в
  разработке не нужна» (его Р0, переносится по Р3) и требование Р2.

### Р1. Главная задача
- **Решение.** Свой язык: краткость синтаксиса и упор на работу с ИИ;
  экономия токенов, скорость сборки, надёжность, проверяемость.
  Совместимость с другими языками по синтаксису — не цель. Подробно и с
  мерами — `docs/direction/GOAL.md`. Решение автора 3 октября 2026.
- **Рассмотрено и отклонено:** диалект, синтаксически идентичный C++20 и
  совместимый с его компиляторами (постановка того же дня).

### Р2. Требования к результату
- **Решение.** Язык:
  - применяется для продолжения разработки VoxelRPG;
  - понятен ИИ (Claude) без проблем;
  - собирает реальные приложения для конечных устройств (у VoxelRPG —
    Android arm64 и Windows x64);
  - меняется так, что игру не переписывают: меняется только компилятор,
    либо игре нужны небольшие правки.
  Решение автора 3 октября 2026.
- **Следствия.** Механизмы (редакции, машинные правки, проверка
  изменений компилятора на VoxelRPG) — предложения исследования (П12),
  ждут решения.

### Р3. Инженерная культура VoxelRPG
- **Решение.** В репозиторий переносится инженерная культура VoxelRPG и
  лучшие практики по исследованию: источник истины — этот файл с
  историей; `ROADMAP/` и `TODO.md`; правила агента в `CLAUDE.md`; коммит
  и пуш после каждого законченного куска; PR в `main` — сразу,
  черновиком; проверки — целевые после задачи, полные перед вливанием;
  поиск секретов; CI в пределах минут закрытого репозитория; хук начала
  сессии. Решение автора 3 октября 2026.
- **Как устроено.** `CLAUDE.md`, `tools/check/`, `.github/workflows/`,
  `.claude/`.

## 3. Выведенные правила

Прямо не выбирались, но следуют из решений и правил VoxelRPG.

- **Перенос части VoxelRPG на язык — решение в `DECISIONS.md`
  VoxelRPG.** Там действует правило «запрос сверяется с решениями», а
  приоритет до выпуска — версия 1 (его Р4). Этот репозиторий решения за
  VoxelRPG не принимает.
- **Код VoxelRPG сюда не копируется.** Защита VoxelRPG — приоритет (его
  Р12: код, его части и выдержки наружу не уходят), а лицензия этого
  репозитория не решена (раздел 5). Из VoxelRPG сюда переносятся правила
  и счёт конструкций, не исходники.
- **Изменение языка после Р0 — с машинной правкой** или с решением
  автора, если правки нет (из Р2).
