# Изменения

Вехи проекта; подробная история — в Git.

## 9 октября 2026 — CLI и тесты в языке

- Компилятор v0.1, шаг 10 — команды `build` (профили `debug`, `release`),
  `test`, `fmt` (сохраняет комментарии и пустые строки), схема JSON
  диагностики (`docs/compiler/cli.md`,
  `docs/compiler/diagnostics.schema.json`).
- Р50: тест — функция с атрибутом `@test`; `dplang test` исполняет
  каждый отдельным процессом в профиле `test` (ASan и UBSan).
- Шаг 11 — стандартная библиотека начата: модуль `os` (Р51) —
  `os.args()`, `os.read_file(path)`, `os.IoError` (`docs/stdlib/README.md`).

## 9 октября 2026 — тесты runtime

- Компилятор v0.1, шаг 9: проход `runtime` в `tests/run.py` — функции
  runtime по одной на граничных значениях, каждая ловушка отдельным
  запуском, вход `dp_run`, запись плавающих против образца, вычисленного
  точной арифметикой (`docs/runtime/README.md`, раздел 9).
- Найдено и исправлено: `str(x)` у плавающих бывала не кратчайшей у
  степеней двойки (`2^-1017` — 17 цифр вместо 16), в компиляторе и в
  runtime одинаково (Р48).

## 7 октября 2026 — онлайн-компилятор: основа (Р49)

- Р49: онлайн-компилятор строится, публичный запуск — отдельным
  решением автора по Р5; в поставляемом профиле `available: false`.
- Ядро: общий вход компиляции `api::check`, предел вложенности E0002
  (`[syntax.nesting]`), контракт v1 `api::compile_v1` со строгим JSON.
- `dplang worker` — процесс на запрос: rlimits, поток компилятора,
  песочница seccomp (нет сети, файлов, процессов, `exec`, исполняемой
  памяти). Временный шлюз на Python stdlib: rate limit, очередь, CORS,
  журнал без исходника. Профиль `service/config/online-v1.json` — по
  замерам.
- Тесты: золотые запросы worker-а, песочница, фаззинг контракта,
  42 теста злоупотреблений по HTTP. Устройство — `docs/service/README.md`,
  контракт для сайта — `docs/service/integration.md`.

## 5 октября 2026 — C-бэкенд

- Компилятор v0.1, шаг 8: C-бэкенд (`compiler/backend_c/`) переводит
  Core IR в C11 без неопределённого поведения; runtime Linux
  (`runtime/`) — ловушки, память, строки, вывод, вход и код выхода.
  Команда `dplang debug c`.
- Различающие тесты: каждая программа набора `run` собирается в
  нативную (gcc и clang, ASan и UBSan) и совпадает с эталонным
  интерпретатором байт в байт. Устройство — `docs/compiler/backend_c.md`,
  `docs/runtime/README.md`.
