# Изменения

Вехи проекта; подробная история — в Git.

## 19 октября 2026 — v0.2 закрыта

- Ворота v0.2 пройдены: треугольник SDL3 + Vulkan запущен на устройстве
  Android автора — кадр равен эталону; на Linux (lavapipe) и на Windows
  под Wine — тоже; повтор `det_sim` совпадает на x86-64 и arm64. Аудит
  версии — `docs/audits/2026-10-17-v0.2-audit.md`.
- Сборки APK для автора — в ветке `apk-builds`, с коммитом в имени
  (`tools/apk/publish.sh`; `CLAUDE.md`, «Сборки APK»).
- Решения автора: цену класса D (Р56) снижать сейчас; О4 — сначала замер
  вариантов. Следующая версия — v0.3.

## 12 октября 2026 — v0.2, шаги 5–6: FFI и привязки

- C ABI в обе стороны (Р59–Р61): `extern fn`, `@link`, `extern type`,
  `@c`, линейные ресурсы, `@export`, тип `extern fn(...)`,
  `dpl build --lib`; на трёх целях.
- Структуры C для привязок (Р62): заимствующие поля, `@count`, `[N]T`,
  `@union`, общее начало, ноль у `@c`; `?H` — указатель или NULL.
  Вызов через таблицу функций — `@slot(N)` (Р63).
- Привязки `bindings/` (Р58): Vulkan 1.3.275 (ядро 1.3 и список
  расширений), SDL3 3.4.18 (заголовки списка), JNI (AOSP). Раскладка
  структур сверяется с заголовками C, программы идут на lavapipe, с
  видео SDL3 offscreen и на JVM хоста (`docs/bindings/README.md`).

## 10 октября 2026 — v0.1 закрыта с оговоркой

- Сделаны все одобренные шаги снижения цены: краткое руководство,
  Р53 `checked_*`, Р54 `Map[K, V]`, приёмы в руководстве («чего нет»,
  частые приёмы). Разрыв с C++ на принятое изменение — +18,4% вместо
  +38,7%; правильность — 60 из 60 с первой попытки
  (`docs/audits/2026-10-10-k2-experiment.md`, раздел 6).
- По решению автора v0.1 закрыта, токенное условие ворот записано
  невыполненным; повторный замер — на v0.4 и с ключом API. Следующая
  версия — v0.2.

## 10 октября 2026 — ворота v0.1: опыт К-2 и снижение цены

- Опыт C++ против dpl на настоящем компиляторе
  (`docs/audits/2026-10-10-k2-experiment.md`). Правильность dpl не хуже
  C++: К-2 не сработал. Расход сессии на принятое изменение у dpl больше
  на 34–45%. Аудит версии — `docs/audits/2026-10-10-v0.1-audit.md`:
  токенное условие ворот не выполнено.
- По решению автора v0.1 не закрыта, цена снижается шагами с замером:
  - краткое руководство `docs/guide/README.md` — разрыв с C++ +23,6%
    вместо +38,7%;
  - Р53 — `checked_add`, `checked_sub`, `checked_mul`, `checked_div`,
    `checked_neg` — +22,8%, в пределах разброса;
  - следующий шаг — `Map[K, V]`.

## 10 октября 2026 — имя языка: dpl (Р52)

## 9 октября 2026 — тесты runtime

- Компилятор v0.1, шаг 9: проход `runtime` в `tests/run.py` — функции
  runtime по одной на граничных значениях, каждая ловушка отдельным

  runtime одинаково (Р48).

## 7 октября 2026 — онлайн-компилятор: основа (Р49)

- Р49: онлайн-компилятор строится, публичный запуск — отдельным
  решением автора по Р5; в поставляемом профиле `available: false`.
- Ядро: общий вход компиляции `api::check`, предел вложенности E0002
  (`[syntax.nesting]`), контракт v1 `api::compile_v1` со строгим JSON.
- `dplang worker` — процесс на запрос: rlimits, поток компилятора,
  песочница seccomp (нет сети, файлов, процессов, `exec`, исполняемой
  памяти). Временный шлюз на Python stdlib: rate limit, очередь, CORS,
  журнал без исходника. Профиль `service/config/online-v1.json` — по
  замерам.
- Тесты: золотые запросы worker-а, песочница, фаззинг контракта,
  42 теста злоупотреблений по HTTP. Устройство — `docs/service/README.md`,
  контракт для сайта — `docs/service/integration.md`.

  интерпретатором байт в байт. Устройство — `docs/compiler/backend_c.md`,
  `docs/runtime/README.md`.
