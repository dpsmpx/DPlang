# DPlang — спецификация ядра (v0.1)

**Статус:** пишется по шагам v0.1 (`ROADMAP/IMPLEMENTATION.md`). Готовы
разделы: 1 (лексика), 2 (грамматика), 3 (модули и имена). Запись — вариант B опыта v0.0 (Р40); решения —
`docs/direction/DECISIONS.md`. Ориентир объёма — 20 тыс. токенов (Р20).

- Нормативный пункт помечен идентификатором: **[lex.int]**. Тест,
  проверяющий пункт, называет его в первой строке: `// spec: lex.int`
  (`docs/policy/TESTING.md`, правило 5).
- «Ошибка» в тексте — ошибка компиляции с кодом из реестра
  (`dplang explain E0101`). «Ловушка» — остановка программы (Р36).

## 1. Лексика

**[lex.source]** Исходный файл модуля — текст в UTF-8 с расширением
`.dpm` (Р46). Неверная последовательность UTF-8 в любом месте файла —
ошибка E0101.

**[lex.newline]** Конец строки — LF (`\n`) или CRLF (`\r\n`). Одиночный
CR — ошибка E0108. Конец строки значим: он завершает инструкцию
(раздел 2).

**[lex.space]** Пробел и табуляция разделяют токены и иначе не значат
ничего.

**[lex.comment]** Комментарий — от `//` до конца строки. Он стоит на
своей строке или после кода в конце строки. Блочных комментариев нет.

**[lex.ident]** Имя — латинская буква или `_`, затем латинские буквы,
цифры и `_`: `count`, `_tmp`, `Vec2`. Регистр различается. `_` отдельно —
имя-заглушка: отбросить значение, пропустить переменную цикла.

**[lex.keyword]** Ключевые слова не могут быть именами:

```
fn struct enum const import pub let var if else while for in match
return break continue defer fail try parallel none true false mut
```

Зарезервированы на будущее (E0109): `unsafe extern errdefer`. Слова
`some`, `ok`, `err` — не ключевые: они значат особое только в образцах
`match` (раздел 6).

**[lex.int]** Целый литерал:
- десятичный `42`;
- шестнадцатеричный `0xFF`;
- двоичный `0b1010`;
- восьмеричный `0o17`.

`_` стоит только между двумя цифрами: `1_000_000`, `0xFFFF_FFFF`.
Значение — не больше 2^64 − 1 (иначе E0106); подходит ли оно типу,
решает проверка типов (раздел 4). Знака у литерала нет: `-1` — унарный
минус и литерал. Буква или цифра сразу за литералом — ошибка E0107.

**[lex.float]** Литерал с плавающей точкой — цифры, точка и цифры
(`1.5`, `0.25`) и/или порядок `e`/`E` со знаком (`2e10`, `1.5e-3`). Цифры
есть по обе стороны точки: `1.` и `.5` — не литералы. `1..5` — литерал `1`,
оператор `..` и литерал `5`. Значение вне `f64` — ошибка E0110.

**[lex.str]** Строковый литерал — текст между `"` на одной строке
исходника (иначе E0103). Он может содержать любые символы, кроме `"`,
`\` и управляющих символов (E0102). Табуляция — допустима. Значение —
байты UTF-8.

**[lex.escape]** Экранирование в строковом и байтовом литералах:

| запись | значение |
|---|---|
| `\n` `\t` `\r` `\0` | перевод строки, табуляция, возврат каретки, байт 0 |
| `\\` `\"` `\'` | обратная косая, кавычка, апостроф |
| `\xHH` | байт с кодом HH (две шестнадцатеричные цифры) |
| `\u{H…}` | символ Unicode — 1–6 шестнадцатеричных цифр, без суррогатов, не больше U+10FFFF; только в строке |

В строке `\xHH` — не больше `\x7f`, чтобы строка осталась UTF-8. Иначе —
ошибка E0104.

**[lex.byte]** Байтовый литерал — один символ ASCII (кроме `'` и `\`)
или одно экранирование между `'`: `'a'`, `'\n'`, `'\xff'`. Тип — `u8`.
Иначе — ошибка E0105.

**[lex.punct]** Операторы и знаки:

```
+  -  *  /  %  +%  -%  *%  &  |  ^  ~  <<  >>  !  &&  ||
== != <  <= >  >=  ??  =  += -= *= /= %= &= |= ^= <<= >>=
.  .. ,  :  => (  )  [  ]  {  }  ?  @
```

Из нескольких подходящих знаков берётся самый длинный: `a<<=b` — это
`a`, `<<=`, `b`. `;` лексер узнаёт, но в грамматике его нет: инструкция
кончается концом строки (раздел 2). Другой символ вне строки и
комментария — ошибка E0102.

## 2. Грамматика

**[syntax]** Запись ниже — EBNF: `{x}` — ноль и больше раз, `[x]` —
необязательно, `|` — выбор, в кавычках — токены. `NL` — один или
несколько концов строки. Разбор не зависит от типов (Р7).

```
module   = { item NL } .
item     = { "@" ident NL } [ "pub" ] ( fn | struct | enum | const ) | "import" ident .
fn       = "fn" ident "(" [ param { "," param } [ "," ] ] ")" [ type ] block .
param    = ident ":" [ "&" [ "mut" ] ] type .
struct   = "struct" ident "{" { field SEP } "}" .
field    = ident ":" type [ "=" expr ] .
enum     = "enum" ident "{" { variant SEP } "}" .
variant  = ident [ "(" type { "," type } ")" | "{" field { "," field } "}" ] .
const    = "const" ident ":" type "=" expr .
SEP      = NL | "," .

type     = "?" type | "!" type | "[" "]" type
         | path [ "[" type { "," type } "]" ] [ "!" type ] .
path     = ident [ "." ident ] .

block    = "{" { stmt NL } "}" .
stmt     = ( "let" | "var" ) ident [ ":" type ] [ "=" expr ]
         | expr [ assignop expr ]
         | "if" cond block [ "else" ( if | block ) ]
         | "while" expr block
         | [ "parallel" ] "for" ident "in" ( "&" [ "mut" ] expr | expr [ ".." expr ] ) block
         | "match" expr "{" { pattern "=>" ( block | stmt ) NL } "}"
         | "return" [ expr ] | "break" | "continue" | "fail" expr
         | "defer" ( block | stmt ) | block .
cond     = expr | "let" ident "=" expr .
assignop = "=" | "+=" | "-=" | "*=" | "/=" | "%=" | "&=" | "|=" | "^=" | "<<=" | ">>=" .

pattern  = alt { "|" alt } .
alt      = "_" | ident | "none" | literal | "-" number
         | ( "some" | "ok" | "err" ) "(" pattern ")"
         | ( "." | ident { "." ident } "." ) ident [ "(" pattern { "," pattern } ")" | "{" fpat { "," fpat } "}" ] .
fpat     = ident [ ":" pattern ] .

expr     = unary { binop unary } .              (приоритеты — expr.prec)
unary    = ( "-" | "!" | "~" | "try" | "&" [ "mut" ] ) unary | postfix .
postfix  = primary { "(" [ expr { "," expr } [ "," ] ] ")" | "[" expr "]"
         | "[" [ expr ] ".." [ expr ] "]" | "." ident | "{" inits "}" } .
primary  = literal | ident | "(" expr ")" | "[" [ expr { "," expr } [ "," ] ] "]"
         | "." ident [ "(" [ expr { "," expr } ] ")" | "{" inits "}" ] .
inits    = [ ident [ ":" expr ] { "," ident [ ":" expr ] } [ "," ] ] .
```

**[syntax.newline]** Конец строки завершает объявление, поле, вариант,
инструкцию и ветвь `match`. Он не завершает их:

- внутри `( )` и `[ ]`;
- внутри фигурных скобок литерала структуры и варианта;
- после бинарного оператора, `=` и оператора присваивания.

Перед `else` перенос допустим. Метод на новой строке (`.name` в начале
строки) не продолжает выражение.

**[syntax.item]** Объявления верхнего уровня — `fn`, `struct`, `enum`,
`const`, `import`. Они идут по одному на строке.
- `pub` делает объявление видимым другим модулям (раздел 3); у `import`
  его нет (E0206).
- Атрибут `@имя` стоит только перед функцией (E0205); `@det` — класс
  детерминированного кода (Р12).
- Поля структуры и варианты перечисления — по одному на строке или через
  запятую.

**[syntax.type]** Типы в записи:

| запись | тип |
|---|---|
| `T`, `m.T` | тип по имени; из модуля `m` |
| `List[T]` | встроенный обобщённый тип (Р42) |
| `[]T` | срез |
| `?T` | может не быть |
| `E!T` | значение `T` или ошибка из перечисления `E` (Р41) |
| `!T` | то же с выводимым типом ошибки (Р41) |

**[syntax.stmt]** Инструкция занимает строку. `;` в языке нет (E0202);
лишние токены после инструкции — ошибка E0204.
- `let` требует начального значения.
- `var` может обойтись без него, если указан тип; тогда переменная
  получает значение позже (раздел 4).

**[syntax.block]** Блок — `{`, инструкции по одной на строке, `}`. Пустой
блок — `{` и `}` на соседних строках. В заголовке `if`, `while`, `for` и
`match` литерал структуры без скобок не пишется: `if p == (Point { x: 0 })`.
Иначе `{` начинает тело.

**[syntax.pattern]** Образцы `match` — раздел 6. `some`, `ok` и `err`
значат особое только перед `(`.

**[expr.prec]** Бинарные операторы — от слабого к сильному. Внутри
уровня — слева направо.

| уровень | операторы |
|---|---|
| 1 | `\|\|` |
| 2 | `&&` |
| 3 | `== != < <= > >=` — не сцепляются: `a < b < c` — ошибка E0203 |
| 4 | `??` |
| 5 | `+ - \| ^ +% -%` |
| 6 | `* / % << >> & *%` |

`<<`, `>>` и `&` — того же уровня, что `*`: `x << 7 * i` — это
`(x << 7) * i`, `v & 0x7f | 0x80` — `(v & 0x7f) | 0x80`.

**[expr.unary]** Унарные `-`, `!`, `~`, `try` и пометки `&x`, `&mut x`
сильнее бинарных: `try f() + 1` — это `(try f()) + 1`. Пометка `&` и
`&mut` стоит только у аргумента вызова и после `for … in` (раздел 8).

**[expr.postfix]** Вызов, индекс, срез и поле сильнее унарных:
`-a.b[i]` — это `-((a.b)[i])`.

## 3. Модули и имена

**[module.file]** Модуль — один файл `.dpm` (Р46). Имя модуля — имя
файла без расширения; оно должно быть именем и не ключевым словом
(E0317). Программа — главный модуль, который назван компилятору, и все
модули, которые он импортирует.

**[module.import]** `import world` делает модуль `world` видимым в этом
файле.
- Поиск — `world.dpm` рядом с главным модулем программы, затем
  стандартная библиотека; не найден — ошибка E0302.
- Повторный `import` того же модуля в одном файле — ошибка E0303.

**[module.graph]** Импорты не образуют цикла, в том числе модуль не
импортирует сам себя (E0301). Модули проверяются в порядке зависимостей.

**[module.scope]** Имена верхнего уровня модуля — его функции,
структуры, перечисления, константы и импортированные модули.
- Повтор имени — ошибка E0304.
- Совпадение с именем импортированного модуля — ошибка E0305.
- Повтор поля, варианта или параметра — ошибка E0318.

Порядок объявлений не важен: функция может вызвать функцию, объявленную
ниже.

**[module.pub]** Другим модулям видно только объявленное с `pub`
(иначе E0306).
- Поля открытой структуры и варианты открытого перечисления открыты
  вместе с ней.
- Открытое объявление не упоминает закрытых типов: ни в сигнатуре, ни
  в полях, ни в вариантах (E0309).

**[module.lookup]** Имя в выражении ищется по порядку:
1. локальная переменная;
2. объявление модуля или импортированный модуль;
3. встроенная функция или встроенный тип (раздел 9).

Не найдено — ошибка E0307. Член модуля — `world.spawn`, `world.Unit`;
вариант перечисления — `Event.Tick`, `world.Kind.Wall`. Нет такого
члена — E0311, нет варианта — E0312.

**[module.local]** Локальные имена — параметры, `let` и `var`,
переменная цикла, `if let`, имена в образцах. Имя видно от объявления
до конца его блока; переменная `let` и `var` — со следующей инструкции.
- Затенения нет: локальное имя не повторяет другое локальное имя,
  видимое в этом месте функции (E0310). В соседних блоках имена могут
  повторяться.
- `_` — не имя: оно отбрасывает значение (`_ = f()`), пропускает
  переменную цикла и подходит к любому значению в образце.

**[module.summary]** Сводка модуля — его открытые объявления с
разрешёнными типами (Р14): сигнатуры функций, поля структур, варианты
перечислений, типы констант. Тел функций и значений констант в ней нет.
Зависимый модуль проверяется по сводке, поэтому правка тела сводку не
меняет. Публичная функция поэтому пишет тип ошибки явно (Р41,
раздел 7). `dplang debug summary` печатает сводки программы.
