# Политика безопасности

Основание — Р4, Р5, `CLAUDE.md` («Защита и оригинальность»).

## 1. Репозиторий и доступ

- Репозиторий приватный (Р5); посторонним не показывается. До v1.0
  наружу не уходят исходники, устройство компилятора, runtime, IR,
  внутренняя документация, история, внутренние наборы замеров и
  закрытая информация VoxelRPG.
- Код этого репозитория и VoxelRPG не вставляется в сторонние сервисы и
  вопросы; поисковые запросы — только общие темы.
- Доступ на запись — у автора и у приложения, через которое работают
  сессии ИИ.

## 2. Секреты

Секретов в репозитории нет: ключей, токенов, паролей, `.env`. Проверяет
`tools/check/check_secrets.py` при каждом полном прогоне. Найденный секрет
— отозвать у сервиса, удалить из истории по решению автора.

## 3. Цепочка поставки

- Зависимости — с закреплённым хэшем и в lockfile (О22); новая
  зависимость — строка в `docs/THIRD_PARTY.md` с лицензией, допускающей
  закрытый проприетарный проект.
- Инструменты (компилятор C, NDK, MinGW, генераторы привязок) —
  закреплённые версии и контрольные суммы.
- Входы генераторов (например, `vk.xml`) — закреплённые версии;
  сгенерированное — в репозитории, дифф — на ревью (О23).

## 4. Компилятор как поверхность атаки

| угроза | мера |
|---|---|
| исходник, вешающий компилятор | лимиты шагов вычислений при компиляции и глубины рекурсии; таймауты в тестах |
| произвольный код при сборке | сценариев сборки нет до v1.0 (О25); вычисления при компиляции — без ввода-вывода |
| вредоносная зависимость | закреплённые хэши, ревью, только git и путь до v1.0 |
| подмена инструмента | закреплённые версии и контрольные суммы |

## 5. Классы серьёзности

| класс | пример | реакция |
|---|---|---|
| критический | ошибка безопасности памяти в runtime или библиотеке; неверный код от компилятора (miscompile); нарушение гарантии детерминизма | блокирует выпуск; регрессионный тест; разбор причины |
| высокий | падение компилятора на корректном коде; ложное «нет ошибки» проверки | исправить до следующей вехи |
| обычный | плохая диагностика, медленная сборка | по очереди `ROADMAP` |

## 6. Сообщения о проблемах

До v1.0 — только автору, в закрытом порядке: запись в `TODO.md` или
задача в сессии. Внешнего канала нет (Р5).
