# Задача t01 на C++

Задание опыта: написать код по постановке.

## Правила

- Работай только в папке `/home/user/C-/build/experiment/k2-r1/t01/cpp`: читай этот файл и `src/`, правь файлы в `src/`. Других файлов не открывай, по диску и в сети не ищи.
- Компилятор и другие программы сам не запускай. Проверка — только командой

      python3 /home/user/C-/bench/experiment.py check /home/user/C-/build/experiment/k2-r1/t01/cpp

  Она собирает его со скрытым драйвером, запускает и сравнивает вывод с ожидаемым; печатает «принято» или первую ошибку.
- Попыток проверки — не больше 5, каждая записывается. Проверяй, когда решение готово целиком, а не для разведки.
- Работа кончается на «принято» или когда попытки кончились. Ответ — одна строка: номер последней попытки и её итог.

## Код

В `src/sol.cpp` — заготовка: объявления, на которые опирается драйвер. Напиши тела функций. Сигнатуры, перечисления и поля структур не меняй; поля структур с пометкой «на ваш выбор» — свои. Вспомогательные функции и типы добавлять можно.

Сборка — `g++ -std=c++20 -O1 -pthread -Wall -Wextra -Werror -fno-exceptions -fno-rtti`, с ASan и UBSan. Драйвер дописывается в конец `src/sol.cpp`.

## t01. Кольцевой буфер целых

Буфер фиксированной ёмкости `capacity` (1…1024) для `i32`, порядок FIFO.

### Интерфейс

- `ring_new(capacity: i32) -> Ring`
- `ring_push(r: &mut Ring, value: i32) -> ошибка Full | ok` — ошибка `Full`,
  если буфер полон; буфер не меняется.
- `ring_pop(r: &mut Ring) -> optional i32` — нет значения, если пуст.
- `ring_len(r: &Ring) -> i32`

### Проверки

Драйвер выполняет последовательность операций и печатает результат каждой
(`expected.txt`).
