## t09. Инвентарь со стопками

`slots` ячеек (1…64). Ячейка пуста или хранит `{ item: i32, count: i32 }`.
Размер стопки: `max_stack(item) = 64`, если `item < 100`, иначе `1`
(инструменты не складываются).

- `add(item, count)`: сначала дополняет существующие стопки этого
  предмета (по возрастанию индекса), затем занимает пустые ячейки (по
  возрастанию индекса). Возвращает остаток, который не поместился (0 —
  всё поместилось). `count > 0`, `item ≥ 1`, иначе ошибка `Invalid`.
- `remove(item, count)`: если всего предметов меньше `count` — ошибка
  `NotEnough`, инвентарь не меняется; иначе забирает начиная с ячеек с
  наибольшим индексом; опустевшая ячейка становится пустой.
- `total(item)` — сколько всего.

### Интерфейс

- `inv_new(slots: i32) -> Inventory`
- `inv_add(inv: &mut Inventory, item: i32, count: i32) -> ошибка Invalid | i32`
- `inv_remove(inv: &mut Inventory, item: i32, count: i32) -> ошибка NotEnough | ok`
- `inv_total(inv: &Inventory, item: i32) -> i32`
- `inv_describe(inv: &Inventory) -> str` — ячейки через пробел: `-` для
  пустой, `item:count` для занятой.
