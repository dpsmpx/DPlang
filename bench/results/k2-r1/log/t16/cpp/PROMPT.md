## t16. Калькулятор целых выражений с переменными

`calc(src)` вычисляет программу из одной строки и возвращает строку:
значение последней инструкции в десятичной записи или ошибку
`error at COL: MESSAGE`. `COL` — номер байта строки, с 1. Значения —
`i64`. Каждый вызов независим: переменные одного вызова другому не
видны.

### Лексика

- Пробел (` `) разделяет лексемы и сам ничего не значит.
- Число — одна или больше цифр `0`–`9`. Знака у числа нет: `-5` — это
  унарный минус и число. Число больше 9223372036854775807 — ошибка
  `number too large` у его первой цифры.
- Имя — `a`–`z` или `_`, затем `a`–`z`, `0`–`9`, `_`.
- Операторы: `+ - * / % ^ ( ) = ;`.
- Любой другой байт — ошибка `unexpected character 'C'`, где `C` — сам
  байт. Во входе только печатные символы ASCII и пробелы.
- Лексема — самая длинная возможная: `2x` — число `2` и имя `x`.

### Грамматика

```
program = stmt { ";" stmt }
stmt    = NAME "=" expr | expr
expr    = term { ("+" | "-") term }
term    = unary { ("*" | "/" | "%") unary }
unary   = "-" unary | power
power   = atom [ "^" unary ]
atom    = NUMBER | NAME | "(" expr ")"
```

`stmt` — присваивание, если это имя и за ним сразу `=`. Бинарные `+ -
* / %` — левые; `^` — правый и сильнее унарного минуса: `-2^2` — `-4`,
`2^3^2` — `512`, `2^-1` — показатель `-1`.

### Порядок работы

1. **Разбор** всей строки — по лексемам слева направо до первой ошибки.
   Ошибка — у первой лексемы, которую нельзя прочитать (ошибки лексики
   выше) или которая не может стоять на своём месте по грамматике; на
   одном месте ошибка лексики важнее. Ошибки грамматики:
   - `unexpected 'T'` — лексема `T` (текст лексемы) не может стоять
     здесь;
   - `expected ')'` — после выражения в скобках нет `)`: у лексемы на
     её месте, а в конце строки — у столбца `длина строки + 1`;
   - `unexpected end` — строка кончилась, а выражение — нет; столбец —
     `длина строки + 1` (пробелы в конце строки входят в длину).
2. Только если разбор прошёл, **вычисление**: инструкции по порядку, у
   бинарного оператора сначала левый операнд, потом правый. Первая
   ошибка вычисления — результат:
   - `unknown variable 'x'` — чтение имени, которому ещё ничего не
     присвоено; столбец — у имени;
   - `division by zero` — делитель `/` или `%` равен 0; столбец — у
     оператора;
   - `overflow` — точный результат `+ - * / ^` или унарного минуса вне
     `i64`; столбец — у оператора;
   - `negative exponent` — показатель `^` меньше 0; столбец — у `^`.

Значение присваивания — присвоенное значение. `/` отбрасывает дробную
часть к нулю, знак `%` — знак делимого. `a % b` с `b = -1` — `0`.
`0^0` — `1`. `^` вычисляется быстро при любом показателе
(`1^1000000000000` — `1`), а `overflow` — только если вне `i64` точный
результат: `(-2)^63` — `-9223372036854775808`.
