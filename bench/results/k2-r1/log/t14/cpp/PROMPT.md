## t14. Параллельная свёртка с детерминированным итогом

Свёртка по рабочим потокам, итог которой не зависит от числа потоков
(`docs/policy/DETERMINISM.md`: фиксированное разбиение, порядок слияния).

### Интерфейс

- `parallel_sum(values: срез f64, threads: i32) -> f64` — значения делятся
  на блоки по 4096 подряд (последний может быть короче). Сумма блока —
  слева направо, начиная с `0.0`; итог — суммы блоков слева направо,
  начиная с `0.0`. Блоки считаются в `threads` потоках (`threads >= 1`);
  итог побитово одинаков при любом `threads`. Пустой срез — `0.0`.
- `parallel_histogram(values: срез u32, buckets: i32, threads: i32) -> список i64`
  — число значений в каждой корзине `value % buckets` (`buckets >= 1`);
  считается в `threads` потоках с локальными счётчиками и слиянием.

Работа действительно делится между `threads` потоками; общих
изменяемых данных без синхронизации нет.

### Проверки

Драйвер — `expected.txt`. Числа `f64` печатаются с 17 значащими цифрами:
итог, посчитанный в другом порядке (например, одной суммой слева
направо), не совпадёт.
