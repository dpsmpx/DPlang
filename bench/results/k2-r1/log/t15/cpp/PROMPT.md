## t15. Книга счетов с вложенными транзакциями

Интерпретатор команд книги счетов. Каждая команда — одна строка текста;
ответ — одна строка. Суммы — целые (копейки), тип `i64`.

### Разбор строки

- Слова разделены одним или несколькими пробелами; пробелы в начале и в
  конце строки не значат ничего. Других разделителей нет: табуляция —
  часть слова.
- Первое слово — команда (таблица ниже), дальше — аргументы. Неизвестная
  команда, пустая строка, не то число аргументов — `error syntax`.
- Имя счёта: от 1 до 16 байт, первый — `a`–`z`, остальные — `a`–`z`,
  `0`–`9` или `_`. Иное — `error syntax`.
- Число: от 1 до 18 десятичных цифр, без знака. Иное — `error syntax`.
  Ведущие нули допустимы: `007` — 7.

### Команды

| команда | что делает | ответ при успехе |
|---|---|---|
| `open NAME LIMIT` | открывает счёт с балансом 0 и кредитным лимитом `LIMIT` | `ok` |
| `deposit NAME AMOUNT` | баланс += `AMOUNT` | `ok BAL` |
| `withdraw NAME AMOUNT` | баланс −= `AMOUNT` | `ok BAL` |
| `transfer FROM TO AMOUNT` | `FROM` −= `AMOUNT + FEE`, `TO` += `AMOUNT` | `ok BAL_FROM BAL_TO` |
| `balance NAME` | — | `BAL` |
| `close NAME` | закрывает счёт | `ok` |
| `begin` | начинает транзакцию (вложенную, если уже идёт другая) | `ok depth N` |
| `commit` | завершает текущую транзакцию, её изменения остаются | `ok depth N` |
| `rollback` | отменяет все изменения текущей транзакции | `ok depth N` |
| `report` | — | открытые счета |

- `BAL` — баланс после команды в десятичной записи (у отрицательного —
  `-`). `N` — глубина вложенности после команды (вне транзакций — 0).
- Комиссия перевода `FEE = AMOUNT / 100` (с отбрасыванием дробной
  части), но не меньше 1. Комиссия никуда не зачисляется.
- `report` — открытые счета по возрастанию имени (байтами), через
  пробел, каждый — `NAME:BAL`; нет открытых счетов — `(empty)`.
- Баланс счёта не может стать меньше `-LIMIT` его счёта.
- Модуль баланса не может стать больше `10^15` (1000000000000000).
- `rollback` возвращает книгу ровно в состояние на момент парного
  `begin`: открытые и закрытые в транзакции счета, балансы — всё.
  `commit` вложенной транзакции передаёт её изменения внешней: их ещё
  может отменить `rollback` внешней.
- Глубина вложенности — не больше 8.

### Ошибки

Команда с ошибкой книгу не меняет. Проверки — строго в этом порядке,
ответ — первая нарушенная:

1. разбор строки — `error syntax`;
2. сумма `AMOUNT` равна 0 — `error amount` (`LIMIT` может быть 0);
3. счёт не открыт — `error unknown NAME` (у `transfer` — сначала `FROM`,
   потом `TO`); у `open` счёт уже открыт — `error exists NAME`;
4. `transfer` со счёта на него же — `error same`;
5. баланс стал бы меньше `-LIMIT` — `error funds`;
6. модуль баланса стал бы больше `10^15` — `error bound` (у `transfer` —
   сначала `FROM`, потом `TO`);
7. `close` счёта с ненулевым балансом — `error nonzero`;
8. `begin` при глубине 8 — `error depth`; `commit` и `rollback` вне
   транзакции — `error depth`.
