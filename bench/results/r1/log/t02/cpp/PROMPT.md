# Задача t02 на C++

Задание опыта: написать код по постановке.

## Правила

- Работай только в папке `/home/user/C-/build/experiment/r1/t02/cpp`: читай этот файл и `src/`, правь файлы в `src/`. Других файлов не открывай, по диску и в сети не ищи.
- Компилятор и другие программы сам не запускай. Проверка — только командой

      python3 /home/user/C-/bench/experiment.py check /home/user/C-/build/experiment/r1/t02/cpp

  Она собирает его со скрытым драйвером, запускает и сравнивает вывод с ожидаемым; печатает «принято» или первую ошибку.
- Попыток проверки — не больше 5, каждая записывается. Проверяй, когда решение готово целиком, а не для разведки.
- Работа кончается на «принято» или когда попытки кончились. Ответ — одна строка: номер последней попытки и её итог.

## Код

В `src/sol.cpp` — заготовка: объявления, на которые опирается драйвер. Напиши тела функций. Сигнатуры, перечисления и поля структур не меняй; поля структур с пометкой «на ваш выбор» — свои. Вспомогательные функции и типы добавлять можно.

Сборка — `g++ -std=c++20 -O1 -pthread -Wall -Wextra -Werror -fno-exceptions -fno-rtti`, с ASan и UBSan. Драйвер дописывается в конец `src/sol.cpp`.

## t02. Разбор строки «ключ = значение»

Разобрать одну строку упрощённого TOML.

- Пробелы и табуляции вокруг ключа, `=` и значения игнорируются.
- `#` начинает комментарий до конца строки (вне строкового значения).
- Пустая строка или строка только с комментарием — результата нет.
- Ключ: `[a-z_][a-z0-9_]*`.
- Значение: целое (необязательный `-`, затем цифры, помещается в `i64`),
  `true`/`false` или строка в двойных кавычках без экранирования.
- После значения допустимы только пробелы и комментарий.

### Интерфейс

- `parse_line(line: str) -> ошибка ParseError | optional Entry`
- `Entry { key: str, value: Value }`, `Value` — сумма: `Int(i64)`,
  `Bool(bool)`, `Str(str)`.
- `ParseError` — `BadKey`, `MissingEquals`, `BadValue`.

### Проверки

Драйвер разбирает набор строк и печатает результат (`expected.txt`).
