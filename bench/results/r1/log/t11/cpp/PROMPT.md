## t11. Физика частиц в фиксированной точке

Частица — `Particle { x, y, vx, vy: i32 }` в формате 16.16 (1.0 = 65536).
Детерминированная симуляция без плавающей точки.

Шаг `step(p)` для каждой частицы:

1. `vy = vy + G`, где `G = -6554`;
2. `x = x + vx`, `y = y + vy`;
3. если `y < 0`: `y = 0`; `vy = -(vy * 3) / 4`; `vx = vx * 7 / 8`.

Деление — с отбрасыванием дробной части к нулю; промежуточные произведения
— в `i64`, результаты помещаются в `i32`.

### Интерфейс

- `step(particles: &mut срез Particle)`
- `checksum(particles: срез Particle) -> u32` — для каждой частицы по
  порядку и каждого поля в порядке `x, y, vx, vy`:
  `h = h * 31 + u32(поле)` по модулю 2^32, начиная с `h = 17`.

### Проверки

Драйвер симулирует 3 частицы 120 тактов и печатает состояние каждые 30
тактов и контрольную сумму (`expected.txt`).
