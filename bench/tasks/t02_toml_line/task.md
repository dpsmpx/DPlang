# t02. Разбор строки «ключ = значение»

Разобрать одну строку упрощённого TOML.

- Пробелы и табуляции вокруг ключа, `=` и значения игнорируются.
- `#` начинает комментарий до конца строки (вне строкового значения).
- Пустая строка или строка только с комментарием — результата нет.
- Ключ: `[a-z_][a-z0-9_]*`.
- Значение: целое (необязательный `-`, затем цифры, помещается в `i64`),
  `true`/`false` или строка в двойных кавычках без экранирования.
- После значения допустимы только пробелы и комментарий.

## Интерфейс

- `parse_line(line: str) -> ошибка ParseError | optional Entry`
- `Entry { key: str, value: Value }`, `Value` — сумма: `Int(i64)`,
  `Bool(bool)`, `Str(str)`.
- `ParseError` — `BadKey`, `MissingEquals`, `BadValue`.

## Проверки

Драйвер разбирает набор строк и печатает результат (`expected.txt`).
