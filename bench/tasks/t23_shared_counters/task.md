# t23. Рабочие с общими счётчиками и флагом остановки

Несколько рабочих берут работы из общего счётчика, складывают итоги в
общие атомарные счётчики и останавливаются все, когда один нашёл
плохую работу.

## Интерфейс

- `cost(v: i64) -> i64` — дано в заготовке: чистая дорогая функция.
- `Totals` — структура: `ok: bool`, `bad: i64`, `count: i64`, `sum: i64`,
  `odd: i64`.
- `run_jobs(jobs: ссылка на список i64, workers: i32) -> Totals` —
  `workers` рабочих (`workers >= 1`) работают одновременно. Рабочий берёт
  номер следующей работы из общего счётчика (каждый номер — одному
  рабочему, по возрастанию) и, пока не поднят флаг остановки:
  - `jobs[j] < 0` — плохая работа: поднять флаг и записать `j` в общий
    наименьший номер плохой работы;
  - иначе `r = cost(jobs[j])` и добавить в общие счётчики: `count` +1,
    `sum` + `r`, `odd` +1, если `r` нечётно.

  Счётчики, флаг и наименьший номер — общие атомарные значения; списков
  результатов рабочие не собирают. Итог: если плохая работа была —
  `ok = false`, `bad` — наименьший номер плохой работы, остальные поля 0;
  иначе `ok = true`, `bad = -1` и счётчики.

Рабочие берут номера по возрастанию, поэтому наименьшая плохая работа
находится всегда, сколько бы рабочих ни было, хотя часть работ после неё
может быть сделана зря.

## Проверки

Драйвер — `expected.txt`: работы без плохих при 1, 4 и 8 рабочих, с
плохими, пустой список, малые списки.
