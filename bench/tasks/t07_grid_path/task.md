# t07. Кратчайший путь на сетке

Карта — строки одинаковой длины: `#` — стена, `.` — проход, `S` — старт,
`G` — цель (ровно по одному). Ходы — на 4 соседние клетки, цена хода 1.

## Интерфейс

- `shortest_path(rows: список str) -> optional i32` — длина кратчайшего
  пути от `S` до `G` в ходах; нет значения, если пути нет.

## Проверки

Драйвер — несколько карт (`expected.txt`).
