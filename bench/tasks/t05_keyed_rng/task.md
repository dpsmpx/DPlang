# t05. Случайность по ключам и высоты рельефа

Детерминированная случайность без общего генератора (как в VoxelRPG и
`docs/policy/DETERMINISM.md`): значение зависит только от зерна и
координат.

## Определения

- `hash32(seed: u64, x: i32, y: i32) -> u32`:
  1. `k = seed ^ (u64(u32(x)) << 32) ^ u64(u32(y))`;
  2. splitmix64: `z = k + 0x9E3779B97F4A7C15`;
     `z = (z ^ (z >> 30)) * 0xBF58476D1CE4E5B9`;
     `z = (z ^ (z >> 27)) * 0x94D049BB133111EB`;
     `z = z ^ (z >> 31)` — все операции по модулю 2^64;
  3. результат — старшие 32 бита `z`.
- `raw(seed, x, y) = 32 + hash32(seed, x, y) % 16`.
- `height(seed, x, y)` — целая часть среднего `raw` в точке и четырёх
  соседях (x±1, y и x, y±1): сумма пяти значений, делённая на 5 нацело.

## Интерфейс

- `hash32(seed: u64, x: i32, y: i32) -> u32`
- `height(seed: u64, x: i32, y: i32) -> i32`

## Проверки

Драйвер печатает `hash32` для нескольких точек (в шестнадцатеричном виде)
и сетки высот (`expected.txt`).
