# t01. Кольцевой буфер целых

Буфер фиксированной ёмкости `capacity` (1…1024) для `i32`, порядок FIFO.

## Интерфейс

- `ring_new(capacity: i32) -> Ring`
- `ring_push(r: &mut Ring, value: i32) -> ошибка Full | ok` — ошибка `Full`,
  если буфер полон; буфер не меняется.
- `ring_pop(r: &mut Ring) -> optional i32` — нет значения, если пуст.
- `ring_len(r: &Ring) -> i32`

## Проверки

Драйвер выполняет последовательность операций и печатает результат каждой
(`expected.txt`).
