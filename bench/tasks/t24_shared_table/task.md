# t24. Общая таблица: читают многие, пишет один

Один писатель меняет общую таблицу, несколько читателей одновременно
читают её целиком. Чтение не должно видеть изменение наполовину.

## Интерфейс

- `Move` — структура: `from: i32`, `to: i32`, `amount: i64`.
- `Report` — структура: `table: список i64`, `reads: i64`, `bad: i64`.
- `run_bank(accounts: i32, moves: ссылка на список Move, readers: i32,
  reads: i32) -> Report` — таблица из `accounts` счетов, у каждого
  вначале 1000. Одновременно идут:
  - **писатель** (один) — переводы по порядку: со счёта `from` на `to`
    переводится `amount`, а если на `from` меньше, — всё, что на нём есть
    (`from == to` — ничего не меняется);
  - **читатели** (`readers >= 1`) — каждый делает `reads` чтений: чтение —
    сумма всех счетов. Перевод сумму не меняет, поэтому верное чтение
    всегда видит `accounts * 1000`.

  Таблица общая; перевод и чтение синхронизированы так, что чтение не
  видит перевод наполовину. Итог: `table` — счета после всех переводов
  по номеру, `reads` — сколько чтений сделано (`readers * reads`), `bad` —
  сколько чтений увидели другую сумму (у верного решения 0).

## Проверки

Драйвер — `expected.txt`: много переводов при 1 и 4 читателях, малые
таблицы.
