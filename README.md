# DPlang

Свой язык программирования (имя — Р38): надёжность, детерминизм и
контролируемость прежде всего; затем проверяемость, скорость разработки
и сборки, работа с ИИ; краткий синтаксис. Сборка приложений для Android и Windows. Изменения
языка — так, чтобы основная стоимость лежала в компиляторе, а не в
переписывании кода потребителя.

Проект закрытый; лицензия проприетарная — [`LICENSE`](LICENSE).
